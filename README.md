# To-Do List

Sistema de gerenciamento de tarefas desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Cadastro de usuários
- Login
- Criação de tarefas
- Edição de tarefas
- Exclusão de tarefas
- Contador de tarefas
- Organização por categorias

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Clone o repositório
2. Abra o arquivo index.html
